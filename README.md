# 철교안 마스터 — 철도교통안전관리자 학습 도구

정적 HTML만으로 동작하며, GitHub Pages에 그대로 올리면 됩니다.

## 시험 개요

- 시행: 한국교통안전공단(TS), **CBT** 방식
- 1교시 교통법규 50문항 / 50분 · 문항당 2점 — **교통안전법 10 · 철도안전법 35 · 철도산업발전기본법 5**
- 2교시 75문항 / 75분 · 문항당 4점 · 과목당 25분 — 교통안전관리론 25 + 철도공학 25 + **선택 1과목 25**(열차운전 / 전기이론 / 철도신호)
- 응시자격 제한 없음(교통안전법 제53조 결격사유자 제외) · 응시수수료 2만원 · 공학용 계산기 지참 가능
- **합격: 과목당 40점 이상 + 전 과목 평균 60점 이상**
- 자격·경력·학위로 2~4과목 면제 가능하지만 **1교시 교통법규는 면제 불가**

## `mock.html`만의 주의사항

실전 모의고사는 문제를 중복 보관하지 않기 위해 다른 과목 페이지(`law.html` 등)를
`fetch`로 읽어 문제은행을 만듭니다. 따라서 **http/https 주소로 열어야** 동작합니다.
파일을 더블클릭해 `file://`로 열면 브라우저 보안 정책 때문에 불러오지 못하고,
그 경우 안내 문구와 함께 버튼이 비활성화됩니다. (다른 5개 페이지는 `file://`에서도 정상 동작)

로컬 확인:

```bash
python -m http.server 8871 --directory "C:\Users\user\Desktop\claude code\cheolgyoan-master"
```

## 수업모드 (class-mode)

과목 페이지 5개에 `links/class-mode.js`가 붙어 있습니다. 교실 화면용으로 확대하고
점수·콤보를 숨기며 교사 툴바를 띄웁니다.

- 켜기: 우하단 🎓 버튼 / 주소에 `?class=1` / `F9`
- 넘기기: `← →` `Space` `PageUp/PageDown`(프레젠터 리모컨) / 탭 이동 `1~9` / 끄기 `Esc`
- 인식 규약은 각 페이지 `<head>`의 `window.CLASSMODE = {...}`로 지정
  (`options:'.opt, .oxbtns button'`, `explain:'.why'`, `correct:'.ok'`, `wrong:'.ng'`).
  탭 현재 위치는 `core.js`가 넣는 `aria-pressed`로 판별합니다.

## 결과 제출 (result-collector)

모든 페이지가 `https://hongyul67-cpu.github.io/links/collector.js` 를 include 합니다.
`?rc=<교사 Apps Script exec URL>` 이 붙은 링크로 열었을 때만 결과화면에
**선생님께 결과 제출** 버튼이 나타납니다. 허브(`index.html`)가 `?rc=`를 각 카드 링크에 자동으로 이어 붙입니다.

링크는 `links-master`의 링크 생성기에서 만들면 됩니다.
